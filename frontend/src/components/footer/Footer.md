# Product Requirements Document (PRD)

# Footer Redesign

### Project: Miss Cheesecake Website (Custom Footer Adaptation)

---

# Overview

The attached reference image should be treated **strictly as a layout, hierarchy, spacing, and content organization reference**. It must **not** be copied visually.

The goal is to recreate the same information architecture and overall layout while redesigning every visual element using the existing **Miss Cheesecake** design language.

The footer should feel like a natural continuation of the website rather than an imported design from another brand.

Every aspect—including typography, color palette, buttons, spacing rhythm, borders, illustrations, icons, animations, hover interactions, and overall premium aesthetic—must inherit the existing Miss Cheesecake UI system.

---

# Objective

Design and develop a completely custom footer that follows the structural composition of the provided reference while remaining visually consistent with the current website.

The reference image should only define:

* Overall layout
* Content grouping
* Section positioning
* Information hierarchy
* Visual balance

Everything else—including styling and interactions—must be redesigned.

---

# Overall Layout

The footer should be divided into three primary sections arranged horizontally on desktop.

## Left Section

Primary website navigation.

Contains:

* Brand logo
* Primary navigation links
* Shopping links

---

## Center Section

Brand personality section.

Contains:

* Large branded visual
* Founder or mascot illustration
* Decorative visual element that reinforces the handcrafted bakery identity

This section acts as the visual centerpiece of the footer.

---

## Right Section

Community & engagement section.

Contains:

* Newsletter signup
* Supporting marketing copy
* Social media links
* Copyright
* Legal links

This section should encourage users to stay connected with the brand.

---

# Visual Language

Although the structural layout follows the reference, every visual element must inherit the existing Miss Cheesecake design language.

Use the existing:

* Typography
* Color palette
* Primary buttons
* Secondary buttons
* Input components
* Border radius
* Shadows
* Hover effects
* Motion language
* Spacing system

Avoid introducing any design that feels disconnected from the rest of the website.

---

# Left Navigation Section

Display the Miss Cheesecake logo at the top.

Below the logo, organize navigation into multiple vertical groups.

Suggested groups:

## Shop

* Shop All
* Cheesecakes
* Gift Boxes
* Seasonal Collection

## Company

* Home
* About
* Story
* Contact

## Explore

* Locations
* FAQs
* Wholesale
* Careers

Navigation links should:

* Follow existing typography
* Have subtle hover animations
* Include smooth color transitions
* Use slight underline or animated indicator on hover

Spacing should remain generous and breathable.

---

# Center Brand Showcase

This section should become the visual highlight of the footer.

Display:

* Founder image
* Bakery illustration
* Brand mascot
* Hero visual

The illustration should not appear static.

Subtle interactions may include:

* Gentle floating animation
* Slight parallax movement
* Fade-in on scroll
* Mouse movement response
* Soft shadow animation

The objective is to make the footer memorable while maintaining elegance.

---

# Newsletter Section

At the top of the right column display an engaging headline.

Example:

> Join the Miss Cheesecake Family

Supporting copy should explain the benefits of subscribing.

Examples:

* New product launches
* Seasonal collections
* Exclusive offers
* Behind-the-scenes stories
* Early access promotions

The copy should feel warm and inviting rather than promotional.

---

# Newsletter Form

Display:

* Email input
* Subscribe button

Use the website's existing input component.

Requirements:

Input:

* Animated placeholder
* Focus transition
* Validation state
* Error state

Button:

Reuse the existing primary button component.

No new button style should be introduced.

Interactions:

* Hover
* Loading
* Success
* Error
* Disabled

---

# Social Media Section

Display branded social buttons.

Possible platforms:

* Instagram
* Facebook
* TikTok
* Pinterest
* YouTube

Buttons should match the site's component system.

Requirements:

* Rounded buttons
* Icon + label
* Hover elevation
* Scale feedback
* Brand-colored hover accent
* Smooth transitions

Avoid using default social media colors if they conflict with the overall design language.

---

# Copyright Section

Display:

* Copyright notice
* Brand signature
* Small supporting text

Example:

© 2026 Miss Cheesecake. Crafted with love.

Typography should be subtle and elegant.

---

# Legal Navigation

Display small footer links.

Examples:

* Shipping Policy
* Refund Policy
* Privacy Policy
* Terms of Service
* Accessibility

Requirements:

* Small typography
* Consistent spacing
* Smooth hover underline
* Existing link styles

---

# Motion Design

The footer should feel alive while remaining subtle.

Include animations such as:

## Scroll Reveal

Footer fades into view as it enters the viewport.

---

## Navigation Links

Hover:

* Underline animation
* Color transition
* Slight translation

---

## Buttons

Hover:

* Elevation
* Scale
* Shadow transition

---

## Newsletter Input

Focus:

* Border animation
* Label transition
* Smooth glow

---

## Social Buttons

Hover:

* Scale
* Shadow
* Icon movement
* Color transition

---

## Center Illustration

Optional interactions:

* Floating animation
* Gentle breathing effect
* Mouse parallax
* Scroll parallax

These animations should remain subtle and never distract the user.

---

# Responsive Behaviour

## Desktop

Maintain the three-column layout.

Navigation, illustration, and newsletter should remain visually balanced.

---

## Tablet

Reduce spacing while preserving the overall hierarchy.

Illustration scales proportionally.

Newsletter remains prominent.

---

## Mobile

Stack sections vertically in the following order:

1. Logo
2. Navigation
3. Illustration
4. Newsletter
5. Social Links
6. Legal Links

Ensure generous spacing between sections.

Buttons should span the available width where appropriate.

---

# Accessibility

Ensure:

* Keyboard navigation
* Visible focus indicators
* Proper heading hierarchy
* Screen reader compatibility
* ARIA labels for newsletter and social links
* Sufficient color contrast
* Touch-friendly tap targets

---

Each component should be:

* Modular
* Reusable
* Easily maintainable
* Fully responsive
* Consistent with the existing project architecture

---

# Design Consistency Rules (Critical)

The provided footer reference **must never be copied visually**. It exists solely to communicate the desired layout, information hierarchy, and structural composition.

Every visual element—including typography, colors, buttons, illustrations, spacing, icons, borders, animations, hover effects, shadows, and interactions—must be redesigned to seamlessly match the existing **Miss Cheesecake** website.

The completed footer should feel like it was designed as part of the original website from the beginning, maintaining the same handcrafted, premium, playful, and elegant personality while serving as a memorable closing section to the user journey.
